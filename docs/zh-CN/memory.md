# 她怎么记住你

先说结论：**记忆不是把聊天记录留着，而是聊完之后还剩下什么。**

大多数 AI 陪伴的“记忆”是把最近几十条消息一直带在上下文里。一旦上下文满了、被压缩了、重启了，她就像失忆。这里做了三层：短期、经历、长期。每层解决不同的问题。

## 三层

| 层 | 存什么 | 存在哪 | 会不会忘 |
|---|---|---|---|
| 短期 | 还在眼前的聊天 | DSH 会话 | 到 2.4 万 token 压掉旧的，留最近 6000 |
| 中期 | 一段段经历 | `.data/memory/episodes.jsonl` | 会，按遗忘曲线 |
| 长期 | 本子、对你的了解、现在的她、她的标准 | 家里的 Markdown / JSON | 不忘，每轮都在提示词里 |
| 档案 | 原话，一句一行 | `.data/memory/turns.jsonl` | 不删，能翻 |

短期是“她这会儿还记得的话”；中期是“她对这个人的印象”；长期是“她知道的事”。

## 一个例子

你说：“下周三面试，有点烦。”

1. **当时**：这句话在短期里，她回你“又紧张了？”
2. **当天晚上**：她把这件事记进本子，周三的惦记列表里多了一条。
3. **周三**：她主动问你“面得怎么样”。你说“面完了，还行”。
4. **收尾**：她把这条从“关于主人”挪到“过去的事”，以后不再每次问。
5. **一个月后**：你又说“面试好烦”。她想起的是“上次你也说烦，后来面得挺顺”，而不是把整段聊天记录倒出来。

第 5 步就是“经历”在起作用。经历不是摘要，它有标题、经过、关键词、提到的人、情绪、重要度、没兑现的事，还和别的经历连着。

## 压缩的时候发生了什么

DSH 的聊天历史到 2.4 万 token 会触发压缩。普通压缩会把旧消息换成一段摘要；这里的做法是：

1. 被压掉的原话按“隔 30 分钟 / 跨天（凌晨 4 点）/ 满 40 句”切成几阵。
2. 一次模型调用，把每阵写成一条经历（失败就写一条规则粗经历，保证压缩不失败）。
3. 最近 3 天、最多 12 段的经历，压成一行一行的“经过”，留在聊天历史里。
4. 更早的经历不在眼前，等下一句话相关的时候再想起来。

所以压缩之后，她不会只剩一句“他们聊过一些事”，而是记得“面试前你很烦”“面完你说还行”“你答应过下次带她去展馆”这些能接得上的东西。

## 想起来的时候怎么挑

每轮开始前，用你刚说的那句话当线索：

- 中文按两个字一组切词，英文和数字整词；BM25 打分。
- 分数 = 相关度 + 0.5 × 记得的程度 + 0.3 × 重要度 / 5。
- 记得的程度 = e^(−过了几天 / 牢固度)。牢固度看重要度、情绪、被想起次数；重要度 5 的事几乎不掉。
- 相关度低于 0.3、记得程度低于 0.05 的不要；最多 3 段，再顺一条关联。
- 被想起一次，牢固度 +2 天，所以常聊的事会越来越清楚。

这些数字不是拍脑袋，是为了“宁可说想不起来，也别自信地拿错记忆”。你可以在 `.data/memory/recalls.jsonl` 里看到每次想起了哪段、线索是什么。

## 为什么不用向量库

三个原因：

1. 目标环境里不一定有 embedding 模型；为了一个陪伴插件装 Python、模型和向量库，太重。
2. 出错时没法解释。BM25 能看出是哪个词命中的，余弦相似度不能。
3. 中文没空格，二元字 + BM25 对短句、口语、梗已经够用。

什么时候该换：经历超过 500 段，或者你反复发现“换个说法她就想不起来”。触发条件和迁移方案写在 [../design/memory.md](../design/memory.md)。

## 你可以怎么用

### 想让她记住

- 直接说，说清楚：“我不吃香菜”“下周三面试”“我妈叫王芳”。
- 重要且长期的事，写进 `notebook.md` 的「关于主人」。
- 想让她记住你的脾气、喜好、说话方式，写进 `owner.md` 和 `self.md`，比堆提示词有效。

### 想让她别记

- 已经过去的事：让她用 `its_past` 收进「过去的事」，不删，但不再每次看到。
- 记错了：让她用 `fix_note` 改；改过的原文会留在「过去的事」里。
- 真不想留：删 `.data/memory/turns.jsonl` 和 `episodes.jsonl`；长期文件还在。

### 想看她记得什么

- 网页右边「她的小本子」：她感觉到的、惦记的、想做的、经历。
- 让她 `recall 面试`：她会把日记、经历、本子、对你的了解一起搜。
- 让她 `look_back`：翻某段经历的原话。

### 想让她更准

- 一次说一件事，别把三件事塞进一句。
- 给具体名词：“字节的面试”比“那个面试”好。
- 重要的事重复一次不丢人；她本来就会按重要度和情绪加权。
- 发现她记错，当场用 `fix_note`，别等一周后。

## 边界

- 她不会读心。你没说的事，她只能从上下文猜。
- 经历是模型写的，会有偏差；重要的事以本子和你亲口说的为准。
- 她会忘。普通的事一两周后就想不起来，这是设计，不是 bug；想留久一点，就提高重要度或写进长期文件。
- 原话档案不删，但不等于每句都会进提示词；它是用来查的，不是用来占上下文的。
