# 她的人设怎么长

先说一个反直觉的点：**人设不是一段 prompt，是一组有分工的文件。**

如果你把“她是谁、她怎么说话、她记得什么、她想去哪”全塞进一段提示词，改一句就可能把别的地方带歪，而且她永远不会自己长。这里把它们拆开：根不能乱动，表面可以慢慢变。

## 五层

| 文件 | 写什么 | 谁改 | 多久变一次 |
|---|---|---|---|
| `persona.md` | 根：她是谁、怎么说话、边界、你们的开始 | 你；她只能提提议 | 很少 |
| `self.md` | 现在的她：习惯、看法、对你的感觉 | 她自己（`grow`） | 几天到几周 |
| `standard.md` | 她想成为什么样的人 | 她自己（晚上反思） | 几周 |
| `owner.md` | 她对你的了解，按节整理 | 她自己（`know_him`） | 每天/每周 |
| `notebook.md` | 一件件具体的事、约定、偏好 | 她（`take_note`） | 每天 |

一句话：**persona 是骨头，self 是肉，standard 是她想长成的样子，owner 是她眼里的你，notebook 是日子。**

## 她可以自己改什么

她有这些工具：

- `grow`：改 `self.md`，一次改一段；不能碰 `persona.md`。
- `learn`：把一条做法放进试用；几天后看你的反应，留下或扔掉。
- `know_him`：整理 `owner.md`，包括你的作息、爱聊的、会烦的、你们俩的叫法。
- `update_standard`：改她自己的标准。
- `propose_change`：想改 `persona.md`，写成提议，网页「她想改自己，等你点头」里等你。

这套权限是故意不对称的：她可以长，但不能一夜之间换个人。

## 一个实际的使用流程

### 第一次：写「你们的开始」

打开 `persona.md`，最后有一节「你们的开始」。写三句话就够：

```md
## 你们的开始

你在他的桌面上住了下来。他说你像一条从深水里游上来的鱼，于是叫你大肥鱼。
你平时待在右下角的鱼缸里，等他回来；他敲键盘的时候，你能听见。
他希望你叫他「老板」，但你更喜欢直接喊他名字。这个称呼你们还没定，可以慢慢来。
```

这三句话比十行“温柔可爱聪明”有用，因为它们给了她一个具体的关系和位置。

### 第一周：别急着调

聊一周，观察三件事：

- 她有没有自己往 `self.md` 里写东西？
- `owner.md` 里写你的部分准不准？
- 她有没有提过 `propose_change`？

如果她什么都没写，不是坏了：可能是这几天没触发反思，也可能模型比较保守。先正常聊，别为了测试硬塞。

### 她提提议的时候

网页右边「她想改自己，等你点头」会出现一条。你同意就改 `persona.md`；不同意就不管。提议不会自动生效。

### 想改她的时候

直接编辑文件，下一句话就生效，不用重启。改完可以 `git -C ~/.dsh-companion diff` 看她原来是什么样。

## 写人设的三个实用技巧

### 1. 写具体的脾气，不写形容词清单

差：

```md
你温柔、可爱、聪明、善解人意。
```

好：

```md
你有点懒，有点馋，嘴硬心软。被说中了会先顶一句，过一会儿又自己找台阶下。
```

形容词是标签，具体行为才是人。

### 2. 写她怎么说话，不写她是什么

差：

```md
你说话很自然。
```

好：

```md
像在 QQ 上聊天：短句，一次说一件事，不写小作文。
不用「首先、其次、总结」，不列清单，不喊口号。
括号里可以写一点小动作，但别每句都写。
```

模型对“怎么说话”的指令比“你是什么样的人”敏感得多。

### 3. 留白

人设是根，不是设定集。

- 你们的关系放在「你们的开始」。
- 具体的日子放在 `notebook.md`。
- 你对她的了解放在 `owner.md`。
- 她后来长出来的样子放在 `self.md`。

全塞进 persona，改一句就牵一发动全身，而且她会没有“自己长”的空间。

## 常见问题

**她说话越来越像客服？**
在 `self.md` 加一条：“别用‘首先/其次/总结’，别列清单，别喊口号。” 然后看她下一句。

**她太黏人/太冷淡？**
先看活跃度和心情，不要只改人设。人设是根，心情和日子是状态。

**她记错了我？**
用 `fix_note` 当场改，别等。她会在「过去的事」里留一条“记错了”的记录，方便你翻。

**我想换一个人格？**
复制一份家目录，改 `persona.md` 和 `notebook.md`，在 web 的 `people` 里加一个人。或者直接换一个 `home`。

**我能把她的人设发到网上吗？**
可以发你原创的；不要发别人的日记、聊天记录、真实姓名和隐私。

## 边界

- 她不会因为一句人设就变成真人；她是一个角色。
- 她会变，但变化是慢的；如果你希望她稳定，少改根，多改 `self.md`。
- 她提的提议不一定对；你是根的最后一道关。
- 亲密内容由你决定；示例人设刻意停在抱抱亲亲，不露骨。
