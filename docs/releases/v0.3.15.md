# v0.3.15 — persona slots and a shared profile

## Added

- Public web persona slots: `people` or `roster` creates `/p/<id>/` with its own chat, memory, diary and signature.
- `sharedProfile` is a single base for birthday, age, city and height; each slot still has its own signature and history.
- `GET/POST /api/profile` on the public web room.

## Why

The private setup had this behavior in the live web plugin. This release makes the contract public without copying `the reference setup` or its private data.
