# v0.3.12 — the desktop window

## The QQ-like window

`@dsh-companion/window` is a standalone Electron window, not a browser tab:

- chat on the left, her mood and recent moments on the right;
- the same transcript as the web room (`/companion/api/*`);
- opened from the desktop pet's **More / Chat with her**, or `/companion-window/`;
- falls back to Chrome `--app`, then the default browser, if Electron is unavailable;
- images now open full-screen: click the image, close with the backdrop, `×`, or Escape.

## Delivery guard

`stripMeta()` catches the model leaking its plan into the visible reply:

```text
按角色：…
回应：…
简短一点。…
```

It keeps the final message, so the window shows the reply rather than the rehearsal.
