# v0.3.2 — history pagination and the integration contract

## Changed

- `GET /api/history` now defaults to the latest 30 rows and accepts `before=<oldest seq>`; responses include `hasMore` and `before`.
- The web client loads older pages when scrolled near the top, preserves the scroll position, and hides the list until the first page is at the bottom.
- Added [docs/integrations/ears-voice.md](../integrations/ears-voice.md): the cross-plugin contract for capture, transcript, TTS-before-history, the `[语音 v-...]` marker, the TTS cache, and failure rules.

## Not in this release

The public packages still do not ship the private host's voice-message UI or TTS cache; the contract documents how to integrate them. The Electron window's fish icon and history-at-bottom behavior are in the public window package.
