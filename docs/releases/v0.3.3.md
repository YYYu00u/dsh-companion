# v0.3.3 — instant history position

## Fixed

- The window's history no longer smooth-scrolls from the first message to the last one. The list is positioned at the bottom while hidden, then revealed; `.list` uses `scroll-behavior: auto`.
- This only affects the Electron window; the web room already used instant scrolling.

## Verification

- `npm test`: 48 passing.
- `npm run check`: clean.
- Manual: open the window with 30+ messages; it starts at the bottom with no visible scroll animation; scroll up to load older pages.
