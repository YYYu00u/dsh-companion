# v0.3.14 — a screenshot she can send

## Added

- `send_screen`: takes a full-desktop screenshot, resizes it to 1280px, and sends it as her own image message.
- `POST /api/her/send`: stores the image, appends it to `.data/her-shots.json`, and merges it into `/api/history`, so it survives a refresh.
- `chatBase` config on `@dsh-companion/core` (default `/companion`).

## Notes

- macOS only for now (`screencapture`); it needs Screen Recording permission.
- This is a screenshot, not video.
- It does not bypass site captchas.
