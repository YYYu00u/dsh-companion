# v0.3.13 — public access without the search gate

## Bilibili without logging in

`bilibili` uses Bilibili's public endpoints:

- `query`: search videos
- `bvid`: read one video's title, UP, duration, views, description
- `mode: popular` / `mode: ranking`: public lists

It returns title, UP, duration, views, and a direct link. No account, no search-page captcha. This is a public-data path, not a captcha bypass.

## Captcha handoff

The hands prompt now says: on a captcha, slider, security check, or scan gate, do not refresh/brute-force/change IP or use a captcha service. For Bilibili search, try public data or `site:bilibili.com` search, then a direct link. If it still blocks, skip and record a wish.
