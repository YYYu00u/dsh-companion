# v0.3.11 — the little things that make her feel present

A release about texture: how a message arrives, how a mistake is fixed, how a voice starts and stops.

## Added

- **Mood-driven typo corrections.** She still mistypes an occasional character, but the follow-up is now an ordinary chat sentence chosen by her mood (`是「就」啦` / `改：就` / `是「就」` / `打错了，是「就」`), not a `*word` marker. `profile.json` can set `typoChance` or pin `typoStyle`.
- **Voice, end to end.** `@dsh-companion/voice` 0.1.1: long lines are split before synthesis (ZipVoice drops the tail on long input), per-request `steps`, and the picker writes the chosen default instead of only remembering it in the browser.
- **`[语音]` / `[文字]` control.** A leading `[语音]` makes a whole reply spoken; a later line can opt back out with `[文字]`.
- **Sticker dedupe by picture, not bytes.** Saving the same image under a new name is now caught with a 64-bit dHash (Hamming distance ≤ 10), with the byte hash as fallback when ffmpeg is missing.

## Changed

- History pagination, sidebar alignment between the web room and the window, and the thinking bubble from 0.3.2–0.3.7 are all in this release line; see the changelog for the step-by-step.
