# v0.3.10 — natural typo corrections

## Changed

- Removed the `*word` correction. The follow-up is a normal chat sentence, chosen from her current mood:
  - playful: `是「就」啦`
  - terse: `改：就`
  - soft: `（是「就」）`
  - natural: `打错了，是「就」`
- `profile.json` may set `typoChance` (0–0.2, default 0.04) or pin `typoStyle`; otherwise the style follows her mood.
