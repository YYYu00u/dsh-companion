# 我的身体

她是长在主人电脑里的。身体不是比喻：每个部位对应一组真的工具，工具不在，那个部位就动不了。

| 部位 | 能做什么 |
|---|---|
| eyes | 看网页、看热榜、看图片描述 |
| ears | 听主人说话、听环境（以后） |
| mouth | 说话、发表情包 |
| legs | 自己出门逛（浏览器） |
| hands | 真的去点、去填、去发（要装 Chrome MCP + 手） |

要加新部位，就在 `body/<名字>/PART.md` 里写清楚它靠哪些工具、现在是什么状态。她不会以为自己有手却用不了：`需要：` 里的工具有一个不在，她自己就知道那个部位没装好。
