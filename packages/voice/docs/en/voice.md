# Local voice

An offline voice for a companion: a small set of reference voices plus local zero-shot cloning (ZipVoice), played on demand in the web room.

## Layout

| Part | Where | Shipped |
|---|---|---|
| Engine | `runtime/tts-server.py`, `src/engine.js` | yes |
| Manifest | `assets/voices.json` | yes |
| Reference audio | `assets/*.wav`, generated by `npm run refs` | no |
| Model | `.models/`, fetched by `npm run models` | no (197 MB) |

Reference clips are **not** shipped: they are TTS output from a cloud provider, so redistribution is best avoided;
users generate them with their own key. The reference transcript must match the audio exactly — cloning aligns the two.

## Setup

```bash
npm run models                 # ZipVoice int8 + vocoder, sha256-verified
VOLC_KEY=xxx npm run refs      # generate the reference clips (needs ffmpeg)
pip install -r runtime/requirements.txt
```

## Speed (M-series Mac, CPU only)

8 steps (default): 1.3 s of speech ≈ 15 s; 7 s ≈ 59 s. 4 steps roughly halves it.
Longer references are super-linearly slower (33 s vs 11 s ≈ 3×).

## Web

`POST /api/say {text}` → wav. Messages starting with `[语音]` get a play button; the marker is stripped.
Synthesis is warmed 1.2 s after the last bubble and cached per `voice|text`.
